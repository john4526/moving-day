# Drive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Copy each person's owned My Drive files and folders with Moving Day, keep the destination in step across a pre-copy and a freeze top-up, and prove it in the scan and the HTML report.

**Architecture:** A `Drive` wrapper in api.py (same retry and error mapping as the others), a `FakeDrive` in tests/fakes.py, ledger tables for Drive items and the shares the tool added, `movingday/drive_copy.py` for copy and top-up, `compare_drive` in compare.py, new validation checks, and wiring in cli.py (`copy --drive`, `check` counts).

**Tech Stack:** as the rest of Moving Day (google-api-python-client, pytest, pytest-html).

**Spec:** `docs/design.md`, section "Drive files (added 19 November 2026, approved)".

**Order:** start only after the contacts work is committed (task C2 of `2026-11-19-contacts.md`: `copy --contacts`, contacts in `check`). Both touch `api.py`, `fakes.py`, `cli.py` and `safeout.py`.

## Global Constraints

- All constraints in `.superpowers/sdd/2026-11-18-migration-utility/common.md` (package `movingday`) still apply.
- Scopes: source adds `https://www.googleapis.com/auth/drive.readonly`; destination adds `https://www.googleapis.com/auth/drive.file`.
- Source credentials only read. The only Drive removals are, on the destination and only on files the tool created: removing a permission the tool added (`permissions().delete`) and moving a file to trash (`files().update` with `{"trashed": True}`). No permanent delete of any file, on either side.
- Every permission create passes `sendNotificationEmail=False`.
- Content passes through memory in chunks of at most `CHUNK = 8 * 1024 * 1024` bytes; never written to disk, never joined into one bytes object for a whole file.
- Ledger stores IDs, versions, modified times, checksums, share fingerprints, states and reason codes only. Never file or folder names, descriptions, or owner/share addresses.
- Output and report: counts only. New output keys go in `safeout.ALLOWED_KEYS`.
- Destination app property key: `movingday_src` (value = source file ID).
- Conversions: `application/vnd.google-apps.document` → `application/vnd.openxmlformats-officedocument.wordprocessingml.document`; `...google-apps.spreadsheet` → `...spreadsheetml.sheet`; `...google-apps.presentation` → `...presentationml.presentation`. Folders are `application/vnd.google-apps.folder`. Every other `application/vnd.google-apps.*` type is unsupported (`application/vnd.google-apps.form` counted separately as forms).

## Review Focus

1. Two files with the same name in one folder → both copied (everything keyed by ID, never by name).
2. A zero-byte upload or an empty Google Doc → copied; checksum check passes for the empty upload.
3. Folders listed child-before-parent, several levels deep → parents still created first; a folder whose parent is not owned by this person goes to the top and is counted as unplaced.
4. A file shared with the owner's own destination address (owner listed in the mapping) → that share is skipped, not failed.
5. A file whose source owner changes to another mapped person between runs → trashed on the first person's destination, copied as new by the second; no failure.

### Task D1: Drive wrapper, fake, ledger tables, scopes

**Files:** Modify `movingday/api.py`, `movingday/runtime.py`, `movingday/ledger.py`, `tests/fakes.py`, `tests/test_no_destructive_calls.py`; Tests `tests/test_api.py`, `tests/test_ledger.py`.

**Interfaces — Produces:**
```python
# api.py
CHUNK = 8 * 1024 * 1024
class Drive(_Google):
    def __init__(self, key_file: str, scopes: list[str])
    def list_owned(self, user) -> list[dict]
        # q="'me' in owners and trashed=false", full pagination; fields per item:
        # id, mimeType, parents, version, modifiedTime, createdTime, md5Checksum, size, name, description, starred
    def list_shared_owners(self, user) -> list[str]      # owner address of each non-owned file the user can open (scan only; never emitted)
    def list_permissions(self, user, file_id) -> list[dict]   # {id, role, type, emailAddress?, domain?, allowFileDiscovery?}
    def download(self, user, file_id) -> Iterator[bytes]       # chunks <= CHUNK
    def export(self, user, file_id, mime) -> Iterator[bytes]   # on 403 exportSizeLimitExceeded, GET exportLinks[mime] with the same creds; if that fails ApiError("export_too_large", False)
    def create_folder(self, user, meta: dict) -> str
    def upload(self, user, meta: dict, chunks: Iterator[bytes], mime: str, convert: bool) -> tuple[str, bool]
        # resumable upload; convert=True asks Google to convert to the Google type in meta["mimeType"];
        # if conversion is refused, retries once unconverted and returns (id, False). Returns (id, converted)
    def update_content(self, user, file_id, chunks: Iterator[bytes], mime: str) -> None
    def update_meta(self, user, file_id, meta: dict, add_parents: str = "", remove_parents: str = "") -> None
    def find_by_src(self, user, src_id) -> str | None   # appProperties has {key='movingday_src' and value=src_id}, trashed=false
    def list_created(self, user) -> list[dict]          # id, mimeType, parents, md5Checksum, appProperties; trashed=false
    def add_permission(self, user, file_id, perm: dict) -> str   # sendNotificationEmail=False always
    def remove_permission(self, user, file_id, perm_id) -> None
    def trash(self, user, file_id) -> None
# runtime.py: Apis gains src_drive, dst_drive (dst None when source_only); scopes per Global Constraints
# ledger.py — new tables
#   drive_items(user_key, src_id, dst_id, kind TEXT 'folder'|'file', src_version, src_modified, md5, src_parent,
#               placed INTEGER, share_fp, state TEXT, reason, PRIMARY KEY(user_key, src_id))
#   drive_shares(user_key, src_id, sig TEXT, dst_perm_id TEXT, PRIMARY KEY(user_key, src_id, sig))
    def drive_rows(self, user_key) -> dict[str, dict]   # src_id -> row as dict (columns above)
    def set_drive(self, user_key, src_id, **cols) -> None   # upsert; unspecified columns keep their value
    def dst_folder(self, src_folder_id) -> str | None   # done folder row of ANY user
    def drive_shares(self, user_key, src_id) -> dict[str, str]   # sig -> dst_perm_id
    def add_drive_share(self, user_key, src_id, sig, dst_perm_id) -> None
    def drop_drive_share(self, user_key, src_id, sig) -> None
    # failures() also counts drive_items rows with state='failed'
```
States: `pending`, `done`, `failed`, `unsupported`, `trashed`. `placed=0` means the file sits at the top of the Drive while its intended folder is not yet copied.

### Task D2: Drive copy and top-up

**Files:** Create `movingday/drive_copy.py`; Test `tests/test_drive_copy.py`.

**Interfaces:**
- Consumes: D1's `Drive`, ledger Drive methods; `calendar_copy.translate_rules(src_rules, mapping, src_user, dst_user, dest_domain)`.
- Produces:
```python
EXPORTS: dict[str, str]          # Google type -> Office type (Global Constraints)
FOLDER = "application/vnd.google-apps.folder"
FORM = "application/vnd.google-apps.form"
@dataclass
class DriveStats:
    folders: int = 0; files_copied: int = 0; files_updated: int = 0; files_moved: int = 0
    files_trashed: int = 0; files_failed: int = 0; kept_as_office: int = 0; unsupported: int = 0
    forms: int = 0; unplaced: int = 0
    shares_added: int = 0; shares_removed: int = 0; shares_failed: int = 0; outside_shares: int = 0
def drive_rules(perms: list[dict]) -> list[dict]     # Drive permission -> {"role","scope":{"type","value"?}} for translate_rules; owner role dropped
def share_sig(role, typ, val, discoverable: bool) -> str   # stable string; also used by compare
def copy_drive(src, dst, ledger, mapping, user_key, src_user, dst_user, dest_domain) -> DriveStats
```
Algorithm for one run (first copy and every top-up are the same code path):
1. `items = src.list_owned(src_user)`; split folders and files; order folders so every parent that is in the owned set comes before its child.
2. Rows whose `src_id` is no longer in `items` and whose state is `done` → `dst.trash`, state `trashed`, `files_trashed += 1`. Rows `pending`/`failed` that are gone → state `trashed` with no call.
3. Target folder for an item: no parent, or the parent is the user's My Drive root → top, `placed=1`. Otherwise, if `ledger.dst_folder(parent)` returns an ID → that folder, `placed=1`. Otherwise (the folder belongs to someone else and is not copied yet, or belongs to someone outside the mapping, which looks the same from here) → top, `placed=0`, `unplaced += 1`. Every run retries `placed=0` items, so they move once their folder is copied; those never placed are the "folder not copied" count in the report.
4. New item (no row, or row `pending`): write row `pending`; if `pending` already, `dst.find_by_src` first and adopt that ID if found. Folder → `create_folder`. Google type in `EXPORTS` → `export` then `upload(convert=True)`; `converted=False` → `kept_as_office += 1`. Other `application/vnd.google-apps.*` → state `unsupported` (`forms += 1` for `FORM`, else `unsupported += 1`), no call. Anything else → `download` then `upload(convert=False)`. Meta: `name`, `description`, `starred`, `modifiedTime`, `createdTime`, `parents` (target), `appProperties={"movingday_src": src_id}`. Then row `done` with version, modified, md5, src_parent, placed.
5. Existing `done` row: version unchanged and parent unchanged and placed=1 → content and placement skipped. Modified time or md5 changed → re-export/download and `update_content` (`files_updated += 1`). Version changed → `update_meta` with name, description, starred. First parent changed, or `placed=0` and the folder now exists → `update_meta(add_parents=new, remove_parents=old)` (`files_moved += 1`).
6. Sharing for every `done` item: `wanted = {share_sig(...): body}` from `translate_rules(drive_rules(src.list_permissions(...)))`; `outside_shares += outside`. If `share_fp` (sha256 of sorted sigs) is unchanged → skip. Else add each wanted sig not in `ledger.drive_shares` (record `add_drive_share`); remove each recorded sig not in wanted (`remove_permission`, `drop_drive_share`); failures count `shares_failed`, never stop the run. Store new `share_fp` only when nothing failed.
7. Per-item loop catches `ApiError` only: state `failed` with reason. Meta SET: `drive_unsupported`, `drive_forms`, `drive_kept_as_office`, `drive_unplaced`, `drive_outside_shares`, `drive_shares_failed`, `drive_trashed`.

**Interfaces:**
- Consumes: D2's `copy_drive`, `DriveStats`, `drive_rules`, `share_sig`, `EXPORTS`, `FOLDER`.
- Produces:
```python
@dataclass
class DriveResult:
    files_src: int; files_dst: int; files_missing: int; folders_src: int; folders_dst: int
    checksum_mismatches: int; acl_missing: int; acl_extra: int; out_of_step: int; folder_not_copied: int
    # folder_not_copied: done rows with placed=0 (their folder was never copied: owned outside the mapping or in a batch not yet run); informational
def compare_drive(src, dst, ledger, mapping, user_key, src_user, dst_user, dest_domain) -> DriveResult
```
- `files_src`: owned, non-folder, not unsupported. `files_dst`: `list_created` non-folders. `files_missing`: source files counted in `files_src` with no `done` row or whose `dst_id` is not in `list_created`. `checksum_mismatches`: non-Google files whose destination `md5Checksum` differs from the source's. `acl_missing` / `acl_extra`: per copied item, translated wanted sigs minus destination sigs, and destination sigs (excluding the owner) minus wanted.
- `out_of_step`: source items whose version, first parent or sharing fingerprint differs from the ledger, plus owned items with no row, plus `done` rows whose source item is gone.
- Validation checks with condition, expected and actual: `test_drive_files_count`, `test_drive_files_missing`, `test_drive_folders`, `test_drive_checksums`, `test_drive_sharing` (acl_missing == 0 and acl_extra == 0), `test_drive_in_step` (0; expected-to-differ under `--expect-changes`, like the mail freeze check). `test_carried_over_notes` adds the Drive meta values from D2 and the fixed line "Comments, suggestions and version history are not carried over."
- `copy --drive`; with no part flags, mail, calendars, contacts and Drive are all copied; per-user entry merges `DriveStats`. Unsupported, forms and kept-as-office never make `ok` false.
- `check` per user adds `drive_files`, `drive_folders`, `drive_bytes`, `drive_unsupported`, `drive_forms`, `drive_shared_from_outside` (files opened via `list_shared_owners` whose owner is not a mapping source address), `drive_in_others_folders` (owned items whose parent is not in their own owned set); summary adds `total_drive_bytes`, `largest_drive_bytes`. Under `--source-only` only the source is touched.
